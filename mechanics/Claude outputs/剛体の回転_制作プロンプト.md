### 2. 共通の物理（この値で作る）

箱は幅 `a`・高さ `b`、静止摩擦係数 `μ`。

| | 傾く（回転する）条件 | すべる条件 |
|---|---|---|
| シム1・2（板を θ 傾ける） | `tanθ ≧ a/b` → **θ₀ = arctan(a/b)** | `tanθ ≧ μ` |
| シム3（高さ b′ で水平に F′ で引く） | `F′·b′ ≧ mg·a/2` → **F′₀ = mg·a/(2b′)** | `F′ ≧ μmg` |

- **先に起こるほうが実際に起こる**。シム1・2 は `μ < a/b` ならすべりが先、シム3 は `μ < a/(2b′)` ならすべりが先。
- 問題の設定（`a = 0.12 m`, `b = 0.16 m`）では `tanθ₀ = 0.12/0.16 = 3/4 = 0.75`（`θ₀ ≒ 36.9°`、`sinθ₀ = 0.60`）、`μ₀ = 0.75`。
- **箱の大きさは「1 マス = 0.04 m」**とする。`a:b = 3:4` が `0.12 m × 0.16 m`（＝問題の設定）。`a:b` のボタンには **2:8 / 3:4 / 4:4 / 8:2** を並べ、**3:4 のときだけ「問題の設定」**と小さく添える。
- 判定の数値は必ず**閉じた式**で出す（数値積分の表から読まない）。

### 3. シム1「板の角度を変える・箱の左下は板に固定」（`r1`）

- 板の**左端をピン（○）で固定**し、θ を変えると板が傾く。**箱の左下も板にピンで固定**（＝箱はすべらず、傾くだけ）。ピンは「蝶番のようなもの・その点を軸に回る」と図中に注記。
- 箱は**4 つ**。左から `a:b = 2:8` `4:4` `8:2`、いちばん右が**操作対象の箱**（既定 `4:4`）。左の 3 つは `a×b = 16`（マス）で面積をそろえる。
- **図の右にズームアップ枠**を置き、操作対象の箱だけを大きく描く（力を観察させるため）。
- **この図だけ 3 次元**。ドラッグで視点が回る（`mk3d` + `attach3dDrag`）。図の左上に**オレンジのボタン 2 つ「斜め上から」「横から」**。既定は「斜め上から」。**いまその視点なら濃いオレンジ、ドラッグでずれたら薄いオレンジ**（`actions[].is` と同じ考え方）。
- 右側の操作：**θ のスライダー**、操作対象の箱の **μ のスライダー**、**a:b をボタンで変更**。**板をドラッグしても θ を変えられる**。
- その下のチェックボックス（**5 つ**、既定は「箱の分割線を表示」だけ ON）
  1. `力を表示` … 重力（重心から）と抗力（接触面から）
  2. `作用線を表示` … 重力の作用線を鉛直に、抗力の作用線を上向きに、それぞれ半直線で伸ばす
  3. `分解した力を表示` … 重力を斜面方向・斜面垂直方向に、抗力を摩擦力・垂直抗力に分解
  4. `各箱の a:b を表示` … 4 つの箱それぞれの下に `a`・`b`・`a/b` を出す（**a/b が小さい順に倒れる**ことに気づかせるため）
  5. `箱の分割線を表示` … 箱を縦 4×横 4 に区切る細い線
- 傾いた箱には**「傾いた！」の吹き出し**（ズームアップ側・左の 4 つの図の両方）。
- ねらい：抗力の作用点が θ とともに動くこと、**倒れるとき重力の作用線が箱の左端（回転軸）を通る**ことを見せる。

### 4. シム2「板の角度を変える・箱は固定なし」（`r2`）

- **真横から見た図だけでよい**（3 次元にしない）。
- 板の左端はピンで固定、**箱は板に固定しない**。θ を上げていくと、箱は**すべる**か**傾く**かのどちらかが先に起こる。
- 箱は 4 つ（左から `2:8` `4:4` `8:2` ＋ 操作対象 既定 `4:4`）。**操作対象以外の μ は操作対象と同じ値**にする。右にズームアップ枠。
- 操作：**θ のスライダー**（板のドラッグでも変えられる）、**μ のスライダー**、`a:b` のボタン。
- **θ のスライダーの目盛りに `θ₀`（傾く角）を打ち、左を「回転しない」右を「回転する」と書く**（構想メモ 図6 の形）。
- スライダーの隣に**「傾く瞬間」ボタン**。押すと `θ₀` の**直前 → θ₀ ちょうど → 直後**を**スローモーション**で見せ、**重力の作用線が回転軸の左へ移って回転が始まる**ところまでを再生する。**このとき「作用線を表示」を自動で ON** にする。
- チェックボックス（5 つ、既定は「箱の分割線を表示」だけ ON）
  1. `力を表示` 2. `作用線を表示` 3. `分解した力を表示`
  4. `各箱の a:b とμを表示` … 各箱の下に `a`・`b`・`a/b`・`μ`・`μ = tanθ を満たす角θ` を出す
  5. `箱の分割線を表示`
- 判定が出たら**「傾いた！」「すべった！」の吹き出し**（ズームアップと左の各図の両方）。
- 図の下に**3 つのセクション**を順に置く。
  - **＜考え方＞**：「①床を傾けていく場合」の 4 コマ図。**教科書の画像を貼らず、canvas で描き起こす**。
    傾きがないとき（力もモーメントもつりあう）→ 少し傾けたとき（**床からの抗力の作用点が中央からずれていく**）→ **傾く直前**（**抗力の作用点が回転軸に一致／重力の作用線が回転軸を通る**）→ 傾いた後（**力のモーメントがつりあわない**）。
  - **＜問題＞**
    - (1) `a = 0.12 m`、`b = 0.16 m` のとき、傾く角度を `θ₀` として `tanθ₀` を求めよ。答えは分数でよい。
    - (2) 直方体と斜面との間の静止摩擦係数 `μ` がある値 `μ₀` より小さいときは、直方体は (1) の状態になる前に斜面をすべり始める。`μ₀` を求めよ。
  - **＜解答＞**：最初はたたんでおき、ボタンで開く（先に答えを見せない）。
    (1) は**「作図による解法」と「力のモーメントのつりあいによる解法」の 2 通り**で見せる。作図のほうは図（重心から下ろした重力の作用線と、対角線・回転軸のつくる直角三角形）を canvas で描き、`sinθ₀ = 0.12/√(0.12²+0.16²) = 0.60`、`tanθ₀ = 3/4` を示す。
    (2) は「`θ₀` を超えるまですべらないためには `θ₀` が摩擦角になっていればよい」→ `μ₀ = tanθ₀ = 0.12/0.16 = 0.75`。**μ が 0.75 より小さいとき、傾く前にすべり始める。**

### 5. シム3「床の上の直方体をばねで引く」（`r3`）

- **真横から見た図だけでよい。**
- 床の上の箱を、**ばねから受ける力 `F′` で左向きに**引く。**ばねはドラッグして伸ばせ、弾性力 `F′` が変わる**。
- 箱は固定なし。`F′` を大きくしていくと、**すべる**か**傾く**かのどちらかが先に起こる。
- 操作：**`F′` のスライダー**、**μ のスライダー**、**`F′` の作用点の高さ `b′`・幅 `a`・高さ `b` はボタン**で変更。**既定は `a:b = 2:8`、`b′ = b`**。
- **`F′` のスライダーの目盛りに `F′₀`（傾く力）**を打ち、左「回転しない」右「回転する」。隣に**「傾く瞬間」ボタン**（`F′₀` の直前・ちょうど・直後をスロー再生。**`F′` と重力の合力の作用線が回転軸の左へ移って回転が始まる**ところまで。**作用線チェックを自動 ON**）。
- チェックボックス（5 つ、既定は「箱の分割線を表示」だけ ON）
  1. `引く力と重力を合成（＝作用線を表示）` … 作用線を表示したうえで、**引く力と重力を作用線上の一点に集めて合成したベクトル**を描く
  2. `力を表示` 3. `分解した力を表示` 4. `各箱の a:b とμを表示` 5. `箱の分割線を表示`
- 判定が出たら箱に**「傾いた！」「すべった！」の吹き出し**。
- 図の下に**＜考え方＞**セクション：「②平らな床で引く場合」の 4 コマ図を canvas で描き起こす。
  引く力がないとき → 少し引くとき（**床からの抗力の作用点が中央からずれていく**）→ **傾く直前**（**抗力の作用点が回転軸に一致／重力と引く力の合力の作用線が回転軸を通る**）→ 傾いた後（**モーメントがつりあわない**）。
- ねらい：**3 力（重力・引く力・抗力）の作用線が 1 点で交わる**こと、**作用点が高いほど倒れやすい**ことを体感させる。
