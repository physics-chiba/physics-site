# ヒーロー配色「黒の地 × 澄んだ青」をほかのシミュレーションに移す指示書

2026-10-27、simple-harmonic-motion.html で千葉さんが採用した配色（案 A「夜の実験室」）。
ほかのページのヒーローも、この配色にそろえるときに読む。**正本は simple-harmonic-motion.html**
（ソースは `src/16_shm.css` の「ヒーロー：黒の地 × 澄んだ青」の節と、`src/85_design.js` の `initStage()` の色）。

## 0. 何をそろえるのか（範囲）

もとの「デザイン統一キット」（`claude/デザイン統一キット.md`）の**黒いヒーロー**を土台にし、
**オレンジ（#e07b18 系）だった UI の部分だけを青に置きかえる**。形・レイアウト・アニメの中身は変えない。

変えるところ（この 2 つ。**ヒーローの中だけ**）：
1. **ヒーロー**の UI：コンテンツ一覧のボタン、副題（t2）、①②③の丸と番号・矢印、パンくずの点、全体スイッチの ON、ステージの操作ボタン（選択中）、live の点、カードのホバー枠、背景の光。
2. **ヒーローの canvas アニメ**の中の「飾りの色」（オレンジの線・文字・光）。
★**ヒーローの外はオレンジのまま**：タブ列（選択中の下線・番号・読み進みの線・「ページ一覧」のアイコン）も、パンくずのロゴ（原子）のオレンジの楕円も変えない（いったん青にしたが、千葉さんの指示でもどした・2026-10-27）。

変えないところ：
- **物理の約束の色は一切変えない**（力・速度・加速度の色、A の赤・B の青、力積のマゼンタ、エネルギーの 3 色など）。
  **加速度のオレンジ `#e07b18` は物理の色なので残す**。「オレンジを使わない」は UI の話。
- 本文の ▶ スタートボタン、ページ一覧パネル（ドロワー）の中、ファビコン（サイト共通。千葉さんが頼んだときだけ）。
- 題名・リード文・カードの式などの**文言**。

★ヒーローの canvas に、物理の量として**青**を使っているページ（例：運動量のページの B ＝ `#5aa7ff`）は、
アクセントの青と見分けにくくなる。物理の色は変えずに、**直す前に千葉さんに「こうなるがよいか」をスクリーンショットで確かめる**。

## 2. CSS（ページ専用の CSS のいちばん最後に足す）

★ページの土台が「デザイン統一キット」の暗いヒーロー（`.hero{background:var(--night)…}` など）になっていることが前提。
なっていないページは、まずキットの 4 章の「ヒーロー」の節をそろえてから、これを足す。
★class 名がちがうページは、役割の対応表を作ってから当てはめる。

```css
/* =========================================================================
   ヒーロー：黒の地 × 澄んだ青（2026-10-27 千葉さん・simple-harmonic-motion と同じ）
   ヒーローではオレンジを使わない（ロゴの楕円と、ヒーローの外のタブ列などはオレンジのまま）。物理の色は変えない。
   ========================================================================= */
.hero{--h-ink:#f4f7fb;--h-txt:243,246,250;--h-sub:rgba(222,232,245,.72);--h-acc:#4fa8ff;--h-acc2:#9fd0ff;--h-accrgb:79,168,255;--h-bg:#0b0e13;
  background:linear-gradient(160deg,#121823 0%,#0b0e13 55%,#0b0e13 100%);color:rgb(var(--h-txt))}
.hero::before{background-image:linear-gradient(rgba(160,200,255,.06) 1px,transparent 1px),linear-gradient(90deg,rgba(160,200,255,.06) 1px,transparent 1px);background-size:40px 40px}
.hero::after{background:radial-gradient(closest-side,rgba(79,168,255,.20),transparent 75%)}
.hero-title{color:var(--h-ink)}
.hero-title .t2{color:#8cc4ff}
.hero .lead2{color:var(--h-sub)}
.hero .tocbtn{color:var(--h-bg);background:var(--h-acc);box-shadow:0 0 0 1px rgba(255,255,255,.1) inset,0 12px 30px -12px var(--h-acc)}
.hero .tocbtn:hover{background:var(--h-acc2);box-shadow:0 14px 34px -12px var(--h-acc)}
.hero :focus-visible{outline-color:var(--h-acc)}
.hero .crumbs{color:var(--h-sub)}
.hero .crumbs a{color:rgba(var(--h-txt),.82)}
.hero .crumbs a:hover{color:#fff}
.hero .crumbs .cs{color:rgba(var(--h-txt),.3)}

```

- そのページのヒーローに、ほかにもオレンジを使った部品（`.stagectl` の e ボタン、独自のバッジなど）があれば、
  同じ考え方で `var(--h-acc)` に置きかえる。**`grep` で `e07b18`・`224,123,24`・`var(--brand)` を探し、ヒーローの中のものだけ**を直す（タブ列・ロゴの楕円はそのまま）。
- simple-harmonic-motion では、題名の「影が左右に単振動する」演出（`.nb::after` の `data-sh`）と、
  広い画面での 2 列レイアウトも入れているが、これは**そのページだけの演出**。ほかのページには入れない（頼まれたら別）。

## 3. ロゴの楕円

パンくずのロゴ（原子のマーク）のオレンジの楕円は**変えない**（サイト共通）。

## 4. ヒーローの canvas アニメの色

- アニメの色の表（`const C = {…}`）の中で、**オレンジ（`#e07b18`・`rgba(224,123,24,…)`・`C.brand` など）を青に**：
  線・点・光 → `#4fa8ff`（`rgba(79,168,255,…)`）、ふち・濃いところ → `#2f7fd6`、明るい粒 → `#9fd0ff`。
- 文字と線の白・グレーは、もとの黒いヒーローのまま（`rgba(243,239,230,…)` など）でよい。
- **物理の量の色（暗い地用の明るい版：赤 `#ff6b5b`・青 `#5aa7ff`・マゼンタ `#ff4fae` など）は変えない**。
- 「いまの e = 0.5」のような**オレンジの強調文字**は、青 `#4fa8ff` か白にする。

## 5. 作業の決まり（いつもどおり）

- 一括の正規表現置換はしない。1 か所ずつ編集する。
- PC のファイルを確認のために作業場所へ写したら、使い終わったらすぐ写しを消す。保存できたかはフォルダの一覧のサイズで確かめる。
- index.html（トップページ）は編集しない。
- 直したら、幅 1440 px と 390 px でヒーローのスクリーンショットを撮り、
  ① オレンジが残っていないか（物理の色は除く）、② 文字が読めるか、③ コンソールのエラーがないか、を確かめてから保存する。
- そのページの設計メモに「2026-10-27 ヒーローを黒 × 青に」と書き足す。
