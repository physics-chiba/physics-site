### 3. モードごとの仕様

#### モード1　運動量と力積の関係

**セクション1　直線上で動く物体（ピコピコハンマーでたたく）**

- なめらかな水平面を、質量 `m` の物体が速さ `v` で等速で動いている。ピコピコハンマーが1回だけ当たり、そのあとは速さ `v′` の等速になる。
- ピコピコハンマーは**簡略化した線画**（頭・柄・グリップ）。**当たる瞬間だけ頭が縮むアニメ**にする。`|F⃗Δt|` が大きいほど**ハンマーの振りを大きく**する。
- 衝突の瞬間、**ハンマーが受ける力と物体が受ける力の両方**を描く（作用・反作用）。
- スライドバーは **`|F⃗Δt|`（力積の大きさ）**。0 にすると速さは変わらない。その下に**質量ボタン `m` `2m` `3m`**（既定 `m`）。
- 図の中に**運動量と力積のベクトル図**（矢印をつないだ一直線の図）を出す。**図の中のベクトルと同じ色**にする。
- たたいた瞬間に**「ピコッ！」の吹き出し**。可能なら小さく音も出す（外部ファイルを使わず Web Audio で短い合成音）。

**セクション2　平面上を動く物体（バットでバントして向きを変える）**

- **真上から見た図**（水平面内の話・重力は考えない）。水平に速さ `v` で飛んできたボールに、進む向きと角 `θ` のバットを当てて向きを変える（バント）。
- `|F⃗Δt|` が大きいなら**バットの振りも大きく**する。
- 図の中に **`mv⃗`・`F⃗Δt`・`mv⃗′` のベクトル三角形**を出す。`|F⃗Δt|` や `θ` を変えると三角形の形も変わる。
- スライドバーは `|F⃗Δt|` と **`θ`** の2本。**既定は θ＝45°、`|F⃗Δt|` はそのとき `|mv⃗′|＝|mv⃗|` になる大きさ（＝ √2 mv）**。
- はねかえった向きを「北西向き」のように**吹き出し**で出す。
- ボタン列・時間バー・グラフはセクション1と同じ。

#### モード3　2物体の弾性衝突（e＝1）

- なめらかな水平面で A が B に追いついて衝突。`conservation-quiz-basic.html` の問1のシーンを利用。
- **3つのセクション**（初期条件だけがちがう）
  - セクション1　A(m, v) → B(m, 静止)
  - セクション2　A(m, 2v) → B(m, v)
  - セクション3　A(m, 2v) → B(2m, v)
- 図の下の立式は**4本**：①運動量保存　②A の運動量変化と力積の関係　③B の運動量変化と力積の関係　④反発係数の式（e＝1）。
- v–t 図は **A と B の2本**（衝突の瞬間に入れかわる）。F–t 図は **A が受けた力と B が受けた力**（大きさが同じで向きが逆＝上下対称）。
- 衝突の瞬間に**「ドンッ！」の吹き出し**と音。
- ＜考え方＞「2物体が受ける力積は大きさが同じで向きが逆（作用・反作用）」→「だから運動量の和は変わらない」の順で見せる。F–t 図の2つの山が上下対称であることと結びつける。

### 4. 使う式（検算に使うこと）

```
力積と運動量        m v⃗ + F⃗Δt = m v⃗′      F⃗Δt = m v⃗′ − m v⃗
接触中の力          F = |F⃗Δt| / Δt（Δt = 0.20 s 固定、接触中は一定）
1次元              v′ = v + |F⃗Δt| / m
バント（既定）      θ=45°、|F⃗Δt| = √2 m v  →  v⃗′ ⊥ v⃗ かつ |v⃗′| = |v⃗|
反発係数（壁）      v′ = −e v、|F⃗Δt| = m(1+e)|v|
斜めの跳ね返り      v_y′ = −e v_y、摩擦なし v_x′ = v_x、摩擦あり v_x′ < v_x
2物体（1次元）      vA′ = ( mA vA + mB vB − e mB (vA − vB) ) / (mA + mB)
                   vB′ = ( mA vA + mB vB + e mA (vA − vB) ) / (mA + mB)
失われた運動エネルギー  ΔK = ½ · mA mB/(mA+mB) · (1 − e²) · (vA − vB)²
```

検算用の値（`check()` に入れる）

- モード3 セクション1（m, v）→（m, 0）：`vA′ = 0`、`vB′ = v`
- モード3 セクション2（m, 2v）→（m, v）：`vA′ = v`、`vB′ = 2v`（そっくり入れかわる）
- モード3 セクション3（m, 2v）→（2m, v）：`vA′ = 2v/3`、`vB′ = 5v/3`（運動量 4mv・運動エネルギー 3mv² がどちらも保存）
- モード4 で `e = 0`：2物体は同じ速度 `(mA vA + mB vB)/(mA+mB)` になり、運動量は保存・運動エネルギーだけ減る
