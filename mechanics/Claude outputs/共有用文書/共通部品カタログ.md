# 共通部品カタログ（シリーズ全体で使いまわす）

`basics-of-motion-on-plane.html` で作った**描画部品と補助関数の一覧**。
新しいシミュレーションのページ（力学的エネルギー保存則、万有引力、…）を作るときは、
**まずこの表を見て「もうある部品」を探すこと**。作り直さない。

実体は `claude/basics-of-motion-on-plane_ソース全文.md` の中の

- `src/40_draw.js` … 矢印・文字・軸・グラフ・手・音（**そのまま丸ごと持っていける**）
- `src/45_defs.js` … 物体の絵（棒人間・かご・木・…）と共通ルール
- `src/50_mode1.js` の先頭 … 斜面の座標系
- `src/60_mode2.js` の先頭 … 放物運動まわり

にある。新しいページでは **`40_draw.js` は基本まるごとコピー**、`45_defs.js` からは必要な絵だけ
持っていく、という使い方を想定している。

⚠ **座標は「画面の px」**（y は下向きが正）。物理の値は `mkView()` などで画面座標に直してから渡す。

## 1. 手・人

| 部品 | 呼び出し方 | 何が出るか |
|---|---|---|
| **手（つかむ・押す・引く）** | `hand(ctx, x, y, ang)` | こぶしが `(x,y)`、腕が `ang` 方向へのびる |
| **下から支える手（手のひら上向き）** | `handUnder(ctx, x, y, sc, flip)` | `(x,y)` ＝ **手のひらのてっぺん（ものが乗るところ）**。指は左へ、腕は右下へ。おもりの下にぴったり接するように置く（mechanical-energy 2-3 で追加） |

| **棒人間** | `stickman(ctx, x, y, ux, uy, s, color, lw)` | `(ux,uy)`＝画面での「上」の向き |
| **観測者（棒人間＋名前）** | `observer(ctx, x, y, ux, uy, name, active, s, lab)` | |
| **人／ボールをける人** | `person(...)` / `kicker(...)` | |
| **糸（ひも）** | `string(ctx, x1, y1, x2, y2)` | 細い茶色の線 |
| **指差しマーク** | `pointerIcon(ctx, x, y, sc)` | `(x,y)`＝指の先。「ここをクリックしてね」の合図（mechanical-energy の「仕事の分析」で追加） |

### スタートのさせ方（どちらを使うか）

- **初速度を与える**なら**デコピン**（`flickStart`）。1-1・1-4・1-8・1-10・2-1・2-2。
- **静かにはなす**なら**手をはなす**（`dropHand`）。1-2・1-3・1-5・1-6・1-12・2-4。
- **ひもで引き続ける**なら**手＋糸**（`hand` ＋ 直線）。2-5。
  `hand(ctx, x, y, ang)` の `ang` は腕がのびる向き。斜面を上へ引くなら `-θ`（rad）を渡す。
  ★機械（ウインチ）ではなく人の手にすること★（先生の指示・第6回。`winch` は使わなくなったので消した）
- **初速度が 0 か正かで切りかえる**シムもある（1-13）。
- ⚠ 手は下や横にはみ出しやすい。**手を出す図は、地面の線を canvas の下から 70 px ほど上げる**。
- ⚠ 糸で引く図は、**斜面を引く長さ $L$ より 3 割ほど長く描く**。同じ長さにすると、
  終わりに物体が巻き上げ機に重なって糸が見えなくなる（2-5 で実際になった）。

## 3. 矢印・文字・角

| 部品 | 呼び出し方 | 備考 |
|---|---|---|
| **矢印** | `arrow(ctx, x1, y1, x2, y2, kind, scale, col)` | `kind`：`force`／`comp`／`vel`／`velx`・`vely`／`acc`／`dim` |
| **文字** | `label(ctx, text, x, y, opt)` | `opt = {size, color, align, bold, halo, avoid}`。白フチつき。`_` で下付き（`v_0`、`x_{eq}`） |
| **吹きだし** | `bubble(ctx, text, x, y, opt)` | `opt = {size, bg, border, color, up, dx}`。**場所を `_txtBox` に記録する**ので、点の吹きだしが避けてくれる |
| **角の弧（θ）** | `angArc(ctx, cx, cy, r, a1, a2, text, labAng, labR)` | **画面の角 ＝ −(数学の角)**。角度の文字は自動でよける |
| **滑車** | `pulleyWheel(ctx, x, y, r)` | 軽くてなめらかに回る車輪。外わく → みぞ → 軸 の順に描く。糸は軸から半径 r の高さを通す（★第20回・モード3で新規★） |
| **加速度ベクトル** | `drawAcc(ctx, x, y, ax, ay, opt)` | `(x, y)` は**物体の中心**。`(ax, ay)` は画面の向きの加速度［m/s²］。**長さは「g のとき 34 px」で全ページ共通**なので、シムをまたいで大きさを見くらべられる。★第17回★ 矢印は **`(nx, ny)` の向きへ `off` px ずらした点を「まん中」にして**描く（速度ベクトルと同じ置き方）。`opt = {nx, ny, off, dx, dy, max}`。既定は真上・44 px。`a` が `(nx, ny)` と逆を向くときは、矢じりが物体まで戻らないよう `off` を `L/2 + 38` まで自動で広げる。図の外へも出ない（`CVW/CVH` でクランプ） |
| **衝突の星／原点マーク／等長の印／色を薄く** | `impact` / `originMark` / `drawEqualTicks` / `fade` | |
| **KaTeX → ふつうの文字** | `texPlain('\tfrac{1}{2}mv_{0}^{2}')` → `½mv_{0}²` | canvas は KaTeX を組めないので必ず通す。`\text{…}`・`^\circ`・添字の `_{…}` に対応 |
| **幅に入るまで縮めて書く** | `labelFit(ctx, text, cx, cy, maxW, size, opt)`（中央）／`labelFitLeft(...)`（左そろえ） | ステップ図の式・見出しの右のひとことに使う |

### ★文字の自動よけ★

`label()` は、**力・速度・加速度・寸法の色**（`COL.force` `norm` `fric` `hand` `vel` `velx`
`vely` `acc` `dim`）で描く文字を、**先に置いた文字とぶつかったら 28 px までの範囲で自動でずらす**。
`opt.avoid: true` でほかの色にも同じことをさせられる。
図の名前・軸・基準面など「動かしたくない文字」には、この色を使わないこと。

### ★速度ベクトルは物体から離して描く★（2026-08 追記）

矢印の始点を**物体の中心**にすると、物体の絵と重なって読めない。
**面のある運動は「面から外向きに 26〜36 px ずらしてから」進む向きへ。
空中の運動は「進む向きと垂直に 22〜30 px ずらしてから」。**
（mechanical-energy の 1-1・1-2 くらいの距離が目安。先生からの指摘で全シムをそろえた。）

⚠ **同じ場所に速度の矢印を2本ならべない。**「本物」と「とちゅうの姿（`midGhost`）」の矢印が
同じ高さに来ると、どちらが今の速度か分からなくなる。**片方を 25〜30 px 上の段へ**ずらすこと
（mechanical-energy 2-4 で必要になった）。

### ★点のエネルギーの吹きだしの決めごと（先生の指示・2026-08）★

> **点の近くにその点のエネルギーを置く。オブジェクトとは重ならないようにする。**

- 吹きだしは canvas ではなく **HTML（`.ptbub`）を canvas の上に重ねて出す**（KaTeX で組むため）。
  `--ptk`（＝ `canvas.clientWidth / d.cw`）で、画面幅が変わっても図に対する大きさが変わらない。
- 中身は **上段＝文字式（KaTeX）／下段＝一回り小さい数値**。
- **点が3つ以上のシムは `d.ptSide = 'stack'`** にすると、吹きだしが
  **canvas の右がわに縦一列**に並ぶ。そのぶん絵は左半分にまとめておくこと。

### ★運動が終わったら、各点に「物体・速度・高さ」を描き直す（2026-08 追記）★

`map(p, m, i)` が返せるもの：

| キー | 意味 |
|---|---|
| `x, y` | 吹きだしの引き出し線がさす点（必須） |
| `ox, oy` | 物体をもう一度描く場所（省略すると `x, y`） |
| `r` ／ `bw, bh, ang` | 丸い物体の半径／四角い物体の大きさと傾き |
| `vx, vy, vlen, voff` | 速度の向き（画面の単位ベクトル）・長さ・物体からの距離 |
| `base, hx` | 高さの両矢印をひく基準面の y と、その x |
| `here` | **いま本物の物体がこの点にいる**（時刻はちがっても場所が同じ）。ばねが自然長にもどってきたときなど |

- **本物がその点にいるとき（`p.t === t` または `here: true`）は、物体と速度は描き直さない**
  （二重に見える）。**高さの両矢印だけは、どの点にも必ず出す**。
  ★これを忘れると、終わりの位置がくらべる点と同じシム（1-4・2-5 など）で高さが1つも出ない★
- **高さの両矢印は点ごとに x をずらす**（`hx: 26 + i * 20` など）。
- **運動中に出している「1本だけの高さの寸法」は、終わったら消す**
  （`if (!endOn(d, s, t)) heightDim(...)`）。消さないと二重になる。
- **`d.midGhost(ctx, s)` を書くと「とちゅうの状態」も描ける**。
  非保存力のシムで「力の向きが運動と逆＝負の仕事」を見せるために使う。
  canvas の大きさは `CVW` / `CVH` を読むこと（引数では渡らない）。
  **置き場所は「時刻の半分」ではなく「A と B のまん中（場所で半分）」にとる**。
  時刻で半分にすると、減速する運動では本物に寄りすぎて重なる（2-4 で実際になった）。

## 6. 力ごとの仕事（mechanical-energy.html・第4回で追加）

「仕事を表示」と「運動エネルギーと仕事の関係」は、**この1か所**から作る。
シム側は `d.forces` に、その図ではたらく力を**名前だけ**並べればよい。

```js
forces: ['g', 'N', 'sp', 'fr']                       // よくある力は名前だけ
forces: ['g', 'N',
  { key: 'pull', name: '糸の力', sym: 'F', color: COL.hand,
    w: function (v) { return v.Ft * P.m25.L; },      // A→B にその力がした仕事 [J]
    wsym: 'W_F = FL\\cos 0^\\circ = FL', why: '…' },
  { key: 'fr', w: function (v) { return -P.m25.fr(v) * P.m25.L; } }]   // 既定を上書き
```

| 名前 | 力 | 仕事の既定 |
|---|---|---|
| `g` | 重力 $mg$ | $U_{g1} - U_{g2}$（保存力なので位置エネルギーの差） |
| `N` | 垂直抗力 $N$ | 0（いつも運動と垂直） |
| `T` | 糸の張力 $S$ | 0（いつも運動と垂直） |
| `sp` | ばねの弾性力 $kx$ | $U_{s1} - U_{s2}$ |
| `fr` | 動摩擦力 $\mu' N$ | $W_B - W_A$（`sample()` が返す非保存力の仕事） |
| `hand` | 手の力 | $W_B - W_A$ |

- `forcesOf(d, v, jj)` … 各力に `W`（点 A → 点 jj の仕事）を入れて返す。
  `jj` を省くといちばん後ろの点。`pairsOf(d, v)` が「A点とB点」などの組を作る。
- `workSign(W)` / `workWhy(W)` … 正・負・0 の判定と、その理由の文（全シムで同じ言い方にそろえる）。
- ★**合計は必ず $K_B - K_A$ に一致する**★ 保存力の仕事を位置エネルギーの差で入れているので、
  $E_2-E_1=W_\text{非保存}$ から自動的にそうなる。
  `90_boot.js` の `work_sum_err_pct` で全シムを検算している（**0.01 % より大きければ直す**）。
  数値積分のシム（1-5・1-6・1-7・1-11・1-13）はごくわずかにずれるので、
  **絶対値ではなく割合で見る**こと。

### ★図の中の力を「クリックできる」ようにするしくみ（2026-08・第5回）★

シムの `draw` を1行も書きかえずに、力をクリックできるようにしてある。

```js
var FKEY_BY_TEXT = { 'mg':'g', 'N':'N', 'S':'T', "μ'N":'fr',
                     '弾性力 kx':'sp', '手の力 F':'hand', 'F':'pull' };
```

- `arrow()` が **kind が `force` の矢印**を描くと `_lastFArrow` におぼえる。
- `label()` が **`FKEY_BY_TEXT` にある文字**を描くと、その文字の箱と直前の矢印を合わせて
  `_forceHit` に登録する（`prep()` でリセット）。
- 使う側は `forceHits()` で受け取り、`d.forces` にある key だけをクリック対象にする。
- ★**力の名前は、この表と同じ文字で書くこと**★
  「弾性力」だけ、「$kx$」だけ、のように書くとクリックできなくなる。
  新しい力を足したら、この表にも1行足す。

## 7. 決めごと（部品ではないが必ず使う）

| 何 | 呼び出し方 | 中身 |
|---|---|---|

| **正の向きの表示** | `drawPosNote(...)` / `posWord(...)` / `areaSignWord(...)` | |

## ★★ 滑車のまわりの描き方（必ず守る。他のページを作るときも同じ）★★

千葉さんの指摘（第20回・第21回）で分かった、**滑車まわりは毎回まちがえる**ところ。
`basics-of-motion-on-plane.html` の 1-10 の描き方が正解なので、それに合わせる。
新しいページで滑車を描くときは、**まずこの節を読む**こと。

### 用語

- **滑車**＝糸がかかる**車輪**そのもの。半径 `pr` は小さめ（**11〜14 px**）。
  大きな輪を描いて中に糸を通すのは間違い。糸は車輪の**ふち（半径 pr）**を通る。
- **支柱**＝車輪を台のはし・天井にとりつける棒。**滑車を宙に浮かせない**。

### 描く順番（ぜったいに守る）

1. `pulleyArm(ctx, つけ根x, つけ根y, PX, PY)` … 支柱
2. 糸の直線部分（A → 接点、接点 → B）
3. `pulleyWheel(ctx, PX, PY, pr)` … 車輪
4. `stringArc(ctx, PX, PY, pr, a1, a2)` … **車輪に巻きついた糸の円弧。車輪のあとに描く**
   （先に描くと車輪が糸をかくして、「糸が途中で消えている」ように見える。第21回の指摘）

### 糸の通し方（水平の台の場合）

    台の上面 ty、A の高さ bh、車輪の半径 pr のとき
      PY = ty + pr − bh/2        ← 車輪の【上】が A の中心の高さになる
      PX = 台のはし cnX + arm    ← arm = pr × 1.9。車輪は台のはしより外に出る
      A からの糸 … (A の右はし, A の中心の高さ) → (PX, PY − pr)   ＝ 車輪の上に接する
      円弧       … −π/2 → 0（上 → 右）
      B への糸   … (PX + pr, PY) → B の上のはし                  ＝ 車輪の右から真下へ
      B の中心 x ＝ PX + pr

### 糸の通し方（斜面の場合）★糸は斜面と平行★

    u＝斜面を上る向きの単位ベクトル、n＝斜面から外向きの単位ベクトル、斜面のはし (tx, ty)
      PX = tx + u.x × arm − n.x × (pr − bh/2)
      PY = ty + u.y × arm − n.y × (pr − bh/2)
      A からの糸 … A の中心（面から bh/2）から u 向きに、(PX + n.x·pr, PY + n.y·pr) へ
                   → これで糸が斜面と**平行**になり、車輪の外がわに接する
      円弧       … atan2(n.y, n.x) → 0
      B への糸   … (PX + pr, PY) から真下

### アトウッド（天井の滑車）

    天井の車輪の中心 (cx, py)、半径 pr
      左の糸 … (cx − pr, py) から真下 → 物体1 の【上のはし】
      右の糸 … (cx + pr, py) から真下 → 物体2 の【上のはし】
      円弧   … ★車輪の【上】を通る★ canvas は y が下向きなので
               ctx.arc(cx, py, pr, Math.PI, 2*Math.PI)（時計まわり＝既定。頂点は 3π/2）
               ※ arc(π, 0, true)（反時計まわり）は【下半分】になる。第23回にこれで
                 まちがえて、糸が車輪の下をくぐっていた（千葉さんの指摘）。
               おもりの間隔は 2pr なので、おもりの半分の幅 ＋ 余白 < pr にする

### 力の矢印

- **張力の作用点は「糸がついている所」**：おもりなら上のはし、台の上のブロックなら糸のつく横のはし。
  物体の中心から描かない（第20回の指摘）。
- 2物体の張力は「A には正、B には負の仕事」。合計 0 の理由を
  「向きが垂直だから」と書いてはいけない（第21回の指摘）。`how:` で理由を差しかえる。

### 糸の長さ（B と滑車のあいだ）

- はじめの B は、滑車から**0.6 m（40 px 以上）**下にぶら下げる。台の高さ `HT` は
  「B のはじめの高さ ＋ 0.9 m」にする。斜面では、てっぺんの高さが「B のはじめの高さ ＋ 0.6 m」に
  なるよう、ふもとの高さを θ から決める（`P.pulSlope.HT(v)`）。

  見た目のために別の点から線を引くと、**糸が面と平行に見えなくなる**（第22回の指摘）。

  図の左はしまで同じ傾きで描き、左はしは縦の線で切る。ハッチも伸ばした分まで渡す。

  印だけだと宙に浮いて見える。ほとんど動かない物体の A・B の印は重なるので、`marks3` は 19 px 未満なら描かない。
- ケース1／ケース2 の説明は「立式のステップ」の最後（`#stepCase`）。左下の式の欄には置かない。

- **スタート時の「支える手」**（第25回）：静かにはなす 2物体のシミュレーションは、つるした物体を
  `releaseHand(ctx, t, x, 物体の下のはし + 2, { side:'up', dx, dy })` で支える。basics の 1-11 と同じ動き
  （t<0.34 で下へ抜けて消える、t=0 だけ「支えている手を放す」）。吹きだしは ○B の印・寸法線・力の字をよけて置く。
