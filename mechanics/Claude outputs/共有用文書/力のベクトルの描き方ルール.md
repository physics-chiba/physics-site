# ベクトル（矢印）の描き方ルール（このプロジェクト共通・絶対に守る）

物理シミュレーション／図を作るときは、**矢印について必ず次のルールを守る**こと。
新しいシミュレーションを作るときも、既存のものを直すときも、例外なく適用する。

## ① 力の矢印は、作用点を「・」ではっきり示す

力の矢印（分力もふくむ）は、**矢印の始点に塗りつぶしの丸（・）を描く**。

- 重力 → 物体の**中心（重心）**に「・」
- 垂直抗力・摩擦力・手で押す/引く力・ひもの張力 → **物体と物体が触れているところ**に「・」
- **万有引力 → 天体の中心（重心）に「・」**。矢印は相手の天体の中心へ向ける。

実装：`arrow()` の中で `kind === 'force' || kind === 'comp'` のとき、
始点に半径 3.1（×scale）の円を**その矢印の色で**描く。

## ② 重なる力の矢印は少しずらす

**同じ直線上に重なってしまう力の矢印は、少しだけ横にずらして両方見えるようにする**。
（例：水平面上の物体の「重力」と「垂直抗力」）

実装：`arrowShift()`。キャンバスを描き直すたび（`prep()`）に記録を空にし、
「向きが平行 かつ 直線どうしのへだたりが 6px 以内 かつ 線分が重なっている」力の矢印を数えて、
右・左・右…と 5.5px（×scale）ずつずらす。ずらすのは力の矢印だけ。

## ③ 大きさが同じ矢印には、同じ本数の「｜」印をつける（力・速度とも）

**長さが同じ矢印（＝大きさが同じ量）には、矢印の途中に垂直な短い線（等長マーク）**をつけて、
ひと目で「同じ大きさ」と分かるようにする。**力どうし・速度どうしで別々に**組をつくる。

- 1組目（いちばん長い組）＝ ｜ 1本、2組目＝ ｜｜ 2本、3組目＝ ｜｜｜ 3本
- 組にならない（1本だけの）長さには印をつけない
- 印は矢じりにかからないよう、矢印の 42 %（最大 len−13）の位置に置く。19px 未満の矢印には付けない
- **許容差は 力 0.8px／速度 0.35px**。速度をきびしくしているのは、
  「ほんの少しだけ速さがちがう2物体」に、まちがって『同じ』の印が出たことがあるため。
  逆に、**ほんとうに同じ速さになる場面（1-12 で速さがそろったあと）で印が出るように、
  速度の矢印は短くても 19px をこえる長さにしておく**（例：`16 + 30*min(1, v/6)`）。

実装：`arrow()` が描いた力・速度の矢印を `_fArrows`（`cat:'F'|'V'`）に記録し、
`d.draw()` のあとに `drawEqualTicks(ctx)` が長さでグループ分けして描く。

**注意**：速度の矢印を「長さ＝大きさ」で比べるので、**同じ図の中では速度の矢印の縮尺をそろえる**こと。
→ 2体問題（作用・反作用）では、**2本の万有引力の矢印は必ず同じ長さ**になる。等長マークが自動で付く。

## ④ 力の矢印は「力の種類ごとに色分けする」

**すべての力を赤で描かない。** 力の種類が変われば色も変える。

| 力の種類 | 色 | 定数 |
|---|---|---|
| 重力・**万有引力**・その他の力（既定） | 赤 `#d1352b` | `COL.force` |
| 垂直抗力 | むらさき `#7b3fd4` | `COL.norm` |
| 摩擦力（静止・動） | 青緑 `#0f8a8a` | `COL.fric` |
| 手の力・ひもの張力 | ピンク `#c2367f` | `COL.hand` |

- **分力は、もとの力と同じ色**（破線＋うすい塗りの矢じり）。
- **矢印につける文字（ラベル）も同じ色**にする。
- 実装：`arrow(ctx, x1, y1, x2, y2, kind, scale, col)` の第7引数 `col` に色を渡す。
- ページ下の凡例（`#legend`）にも色を並べて出す。

## ⑤ 速度を分解したら、かならず角 θ′ を書き入れる ★

**平面内の運動で「分解した速度を表示」にしたときは、
`v_x` の向きと、もとの速度 `v` の向きがつくる角を `θ′` として図に書く。**
「分解」と「合成」が角でもつながることを見せるため。

実装：`drawVelAngle(ctx, px, py, m, L)`（60_mode2.js）。
`drawVel()` の中から `showC` のときに自動で呼ばれる。
自前で `velx`／`vely` を描いているシミュレーション（2-1・3-2・3-3）でも、同じ関数を明示的に呼ぶこと。

- 弧の半径は矢印の長さの 42 %（13〜34 px）、矢印が 22 px より短いときは書かない
- `θ′ = atan(|v_y| / |v_x|)` を度で表示
- `v_x` が左向き（負）のときも、`v_x` の向きから測る

## 「正の向き」の書き方 ★

図の中に出す「正の向き」の表示は、**全シミュレーションで同じ形にそろえる**。

```js
drawPosNote(ctx, d, s, W, y, word);   // → 「正の向き：下向き」
```

- かならず **「正の向き：○○」**（「下向きが正」などバラバラに書かない）
- ○○ は `signLabels`（グラフの「正とする向き」ボタン）から自動生成するので、
  向きを切りかえると図の表示もいっしょに変わる
- 斜面など、状況で言い方が変わるものは第6引数 `word` に `dirWord()` の結果を渡す
- 位置は**図の右上、時刻の下**にそろえる
- ※ **軌道運動のページ（celestial-mechanics.html）では「正の向き」は出さない。**
  平面内をぐるぐる回る運動では「右向きが正」に意味がないため、
  `signLabels`／`s.sign` の仕組みごと使っていない。
- ※ **エネルギーのページ（mechanical-energy.html）でも出さない。**
  エネルギーはスカラーで向きがないため（同じく `signLabels` ごと使っていない）。

## 棒人間の描き方

- 腕は**ひじで曲げる**。まっすぐ左右に伸ばすと、2本が1本の棒になって
  体を串刺しにしているように見える（`kicker()`・`person()` で実際に起きた）。
- 腕は**頭にかからない高さ**から出す。
- 観測者の棒人間は別ドキュメント「観測者の描き方ルール.md」を参照。

## ⑥ 「力・速度・加速度の色」を、ほかのものに使わない ★（2026-08 追記）

新しいページを作るときに**新しく色が必要になっても、上の表の色は絶対に使い回さない**。
生徒は2つのページを行き来するので、同じ色がちがう意味で出てくるのがいちばん困る。

空いているのは **黄・緑・金・茶・濃いグレー**。ここから取る。
`celestial-mechanics.html`（万有引力）で足した色は次のとおり。`COL` に定義し、`#legend` にも並べてある。

| 用途 | 色 | 定数 |
|---|---|---|
| 太陽・中心の天体 | 黄 `#f0b429`（フチ `#c07f00`） | `COL.sun` / `COL.sunRim` |
| 軌道（予定の道すじ） | うすいグレー `#98a2ac` | `COL.orbit` |
| 円・楕円軌道（力学的エネルギー E<0） | 緑 `#1c8f4a`・実線 | `COL.bound` |
| 放物線（E=0） | 金 `#b58900`・破線 | `COL.para` |
| 双曲線（E>0） | 濃いグレー `#3f4a54`・一点鎖線 | `COL.hyper` |
| 面積速度の扇形 S₁／S₂／S₃ | 緑 `#1c8f4a`／金 `#b58900`／茶 `#8a5a2b`（うすい塗り＋実線のフチ） | `COL.sect1〜3` |
| 共通重心 | 濃いグレー `#3f4a54` | `COL.cg` |
| 星空の地（天球の図） | 濃紺 `#22304a` | `COL.sky` |

- **軌道の種類は「色」だけでなく「線の形」でも分ける**（`orbColor()` / `orbDash()`）。
  円・楕円＝実線、放物線＝破線、双曲線＝一点鎖線。色覚特性への配慮。
- **天体そのものの色（水星・金星…）は「塗り」なので、上の矢印の色とは別枠**にする。
  矢印の凡例（`#legend`）とは分けて、`.plegend`（天体の凡例）に出す。
- 濃い背景（天球の図）に文字を書くときは、`label()` の `haloColor` を
  `rgba(34,48,74,.9)` にして、文字色を明るくする（白フチのままだと読めない）。

## ⑦ エネルギーの3色（2026-08 追記・mechanical-energy.html）

「力学的エネルギーと非保存力の仕事の関係」のページで足した色。**この3つだけ**。
力・速度・加速度の色は1つも流用していない。

| 用途 | 色 | 定数 | 線の形 |
|---|---|---|---|
| 運動エネルギー $K$ | 緑 `#22a465` | `COL.eK` | 実線 |
| 位置エネルギー $U$ | 茶 `#63390c` | `COL.eU` | 破線（弾性エネルギー $U_s$ は同じ色の点線） |
| 力学的エネルギー $E$ | 濃い青灰 `#38475a` | `COL.eE` | 太い実線（線幅 3.2） |
| 非保存力の仕事で失われた分 | グレー `#7a8794`（既存の `COL.areaNeg`） | — | うすい塗り＋破線のふち |

- **色だけでなく線の形でも分ける**（K＝実線／U＝破線／E＝太い実線）。色覚特性への配慮。
- **グラフの線・図の中の棒（`energyBar`）・表・式の中の記号・凡例で、必ず同じ色を使う。**
- 色覚多様性のチェックずみ（P型・D型・T型をシミュレートして CIEDE2000 で比較）。
  **3色どうしの最小ΔEは、どの視覚型でも 25.8**（15 以上あれば十分）。
  既存の矢印の色との最小ΔEは、ふつうの見え方で 18 以上。
  ★緑と茶は「D型（第2色覚）でいちばん近づく」組み合わせなので、
  　明るさ（L\*）を大きく変えてある（緑 L\*≈61 / 茶 L\*≈29）。色を選び直すときはここに注意★
- **基準面（位置エネルギーの h = 0 の線）は、U と同じ茶の破線**で描き、
  「基準面 h = 0」と必ず書く（`datumLine()`）。

## ⑧ 図の中の矢印につける文字は「記号だけ」にする ★（2026-08 追記）

`mg` `N` `S` `μ'N` `v` のように**記号だけ**を書き、**数値は図の外**
（計算結果の帯 `.resbar` と読み出しの表）に集める。

- 「重力 mg = 9.8 N」のような長いラベルにすると、物体が動いたときに
  寸法線・角・基準面の文字と**必ずどこかでぶつかる**（mechanical-energy で実際に起きた）。
- 置き場所も決めておく：**重力＝矢じりの下（中央）／垂直抗力・張力＝矢じりの先／
  速度＝矢印の先**。こうすると、向きのちがう矢印のラベルどうしは自然に離れる。
- 図の中の「結論のひとこと」は canvas の中に書かず、**図のすぐ下の HTML の行**に出す。
  canvas の下すみに書くと、下向きの重力の矢印のラベルと必ずぶつかる。

## ⑨ 2物体の図では「どちらの物体にはたらく力か」を色の濃さで分ける ★（2026-09 追記）

**2つの物体を同時に描く図（basics-of-motion-on-plane の 1-9〜1-12、モード3 の 3-1〜3-3）では、
生徒が「A にはたらく力」と「B にはたらく力」を見分けられるようにする。**

- **力の種類の色（④の表）はそのまま**使う。種類の情報は消さない。
- **A にはたらく力＝あかるい色（④の表のまま）／B にはたらく力＝同じ色みの「こい色」**。
- あわせて、**矢印の文字に「A：」「B：」を付ける**（例：`A：mg` `B：Mg` `B：動摩擦 4.90 N`）。
  ※ 1物体だけの図では ⑧ のとおり記号だけでよい。**2物体の図だけの決めごと**。
- 図の下の説明文（`sub`）にも
  「力の矢印は A＝あかるい色／B＝こい色で描き分けている」と1行入れる（`OBJCOL`）。

実装：`fcol(who, col)`（40_draw.js）。`who` が `'B'` のとき `COL_B` の表で暗い色に置きかえる。

| 力の種類 | A（あかるい） | B（こい） |
|---|---|---|
| 重力 | `#d1352b` | `#7a1710` |
| 垂直抗力 | `#7b3fd4` | `#3f1f7a` |
| 摩擦力 | `#0f8a8a` | `#0a4f4f` |
| 手・ひもの力 | `#c2367f` | `#711a49` |

```js
arrow(ctx, x1, y1, x2, y2, 'force', 1, fcol('B', COL.force));
label(ctx, 'B：Mg', x, y, { color: fcol('B', COL.force) });
```

## ⑩ 作用・反作用の2力は「同じ作用点」に描く ★（2026-09 追記）

**作用・反作用の関係にある2力は、作用点（矢印の始点）が同じ点**になる。
図の上でまったく同じ点に描くと2本が重なって見えないので、
**その点から 4px ほどだけずらして描く**。大きくずらして別の場所に描いてはいけない。

例：1-12（板 A と、その上の物体 B）の摩擦力は、**A と B がふれあっている面**が作用点。
B にはたらく動摩擦を面の 4px 上に、A にはたらく反作用を面の 4px 下に描いている。

## ⑪ ひもと滑車のかかり方（2026-09 追記）

**滑車にかけた糸は「滑車の外がわ（接線）に接して、円周にそって回りこむ」**。
糸を滑車の中心に向けて引いてはいけない（1-10 で実際にまちがえた）。

- 物体の側の糸が面と平行なら、**その直線が滑車の接線になるように滑車の位置を決める**。
  面の上の物体では、糸（＝物体の中心を通る面と平行な線）が接線になるよう、
  滑車の中心を「面から (r − 物体の高さ/2)」の位置に置く（教科書の図と同じ形）。
- 接点は `滑車の中心 + n * r`（n は面から外向きの単位ベクトル）。
- 巻きついている部分は円弧で描く（`stringArc()`）。
- **張力の矢印の作用点は、糸と物体が接している点**（物体の中心ではない）。
- ★**滑車は必ず「支柱」で台のはしに取りつける**★。宙に浮いた滑車を描かない（1-10 で実際にまちがえた）。
  教科書の図と同じで、台のはしから滑車の中心へ、長さ **1.9 r** ほどの太い棒（外枠つき）を描き、
  そのうえに滑車をのせる。滑車の中心の高さは、糸が面と平行になるように
  「面から (r − 物体の高さ/2)」で決まるので、支柱はほぼ面と平行の向きになる。

## ⑫ 吹き出しのしっぽは「指し示すもの」の向きに出す ★（2026-09 追記）

**吹き出しのしっぽ（三角）は矢印と同じで「どれについて言っているか」を指す印**。
かならず**指し示したいものの方向**へ向ける。下向きで固定しない。

- 対象が吹き出しの**左**にある → `side:'left'`（箱は右、しっぽは左向き）
- 対象が**右** → `side:'right'` ／ **上** → `side:'up'` ／ **下** → `side:'down'`（既定）
- `'up' / 'left' / 'right'` では `(x, y)` は**しっぽの先＝指したい点**。`'down'` だけは
  これまでのシムとの互換のため `(x, y)` が箱の下辺の中央（しっぽの先はその 8px 下）。

実装：`bubble(ctx, text, x, y, opt)`（40_draw.js）。
例：1-10・1-11 の「支えている手を放す」は、手の右に箱を置いて `side:'left'` で手を指している。
