## 千葉さんが決めたこと（主なもの）
- 呼び方は「千葉さん」。生徒が読む文に「シム」と書かない。教科書のページ・問番号は書かない。
- 速度の矢印は物体や力の矢印に重ねず、物体の上（少し離して）。重力と垂直抗力（浮力・弾性力）が同じ線上なら左右にずらす。弾性力はばねとの接点から。
- ばねの太さは k で変わる。φ の字形は ϕ（KaTeX マクロ \varphi→\phi）。時間バーの右は「周期 T = 〇 s」。
- 力の表示は 2 つのチェック「合力のみを表示」「全ての力を個別表示」。
- 1-2：k の既定 5 N/m。コマ送りは光らせる。おもりの数を変えても止めない（ωt を保つ）。「変位 x／速度 v／加速度 a に注目する」を押すと、成分の分解・x 軸への映し・色ぬりをそのまま出し、となりに光るコマ送り。「さらに詳しく」は廃止。ωt+ϕ = ±π/2 で、円の加速度ベクトルと x 軸上の映しに「＝」の印（変位・速度の「‖」と区別）。円の v・a にはベクトルの記号。
- 1-3：導出は x = A sin(ωt+ϕ)、v = Aω cos(ωt+ϕ)。弾性力は合力と同じ縮尺、mg と N は「縮めて描いている」と注記（弾性力が 2px 未満になって消えていたため）。2-5 の摩擦力も同じ理由で横向きの力を大きい縮尺に。
- 振動の様子を並べた図：場面ごとに仕切り線。拡大図は body 直下の position:fixed（z-index 9000）で、ホバーしたセルの上に出す（下段なら上段のあたり。上に場所がなければ下）。
- 2-7：アニメの左に「底面が液面と同じ高さのとき」「つりあいのとき」（水槽は 1 つ）。
- 2-8 地球トンネル：celestial-mechanics.html#m3-2 を簡潔に。時刻は分（d.tFmt）。「詳しくはこちら」のリンク。3-1 の表にも行を追加。
- 3-1：表の色ぬりなし。「ばねによる振動と単振り子の ω、T はうっすら覚えておこう。」比較の前に「例：3 つの振り子の比較」。
- ヒーローの式③の下線 U は #3-2 へ。85_design.js の initIdeas は、節のアドレス（#3-2 など）なら parseHash → activateMode → scrollToSec（以前は章の id だと思って何もしなかった）。
