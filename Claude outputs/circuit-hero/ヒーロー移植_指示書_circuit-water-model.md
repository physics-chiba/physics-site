作成 2026-10-27。いっしょに渡すファイル：**`ヒーロー見本_simple-harmonic-motion.html`**（ブラウザで開くと本物と同じヒーローが動く見本）。

## 0. ねらい

楽楽（らくらく）高校物理・力学の `simple-harmonic-motion.html`（単振動）の**ページ冒頭の大きな見出し部分（ヒーロー）**を、
電磁気の `circuit-water-model.html`（電気回路 3 次元シミュレーション／水流モデル）にも付けて、サイトの見た目をそろえる。

- **見た目（色・形・余白・動き方）は見本とまったく同じ**にする。
- **中身（題名・説明・アニメ・3 つのカード）は、電気回路のページ用に作りかえる**。
- ヒーローより下の、いまのページ（回路を組む画面・立体図・解説・保存など）は**変えない**。

## 1. 見本ファイルの中身（4 つ）

`ヒーロー見本_simple-harmonic-motion.html` は、単振動のページからヒーローだけを取り出したもの。中は次の 4 つ。

| 部分 | 持っていくか | 中身 |
|---|---|---|
| style 要素 `id="demo-fonts"` | **持っていかない** | KaTeX のフォント。見本を単独で開くためだけ。circuit-water-model.html にはもう KaTeX が入っている |
| style 要素 `id="hero-css"` | **そのまま持っていく**（一字も変えない） | ヒーローの CSS。動いているページから自動で集め、**すべての規則の頭に `#hero` を付けてある**。だから、ページのほかの部品・CSS 変数（`--ink` `--bg` など）・`body` には一切効かない |
| header 要素 `id="hero" class="hero"` | 形をそのまま持っていき、**文言・式を書きかえる** | ヒーローの HTML |
| script 要素 `id="hero-js"` | 持っていき、**アニメの絵（draw）を作りかえる** | ステージのアニメ（`initStage`）とコンテンツ一覧のパネル |

★`hero-css` の中は、circuit-water-model.html の CSS と名前がぶつかる class（`.topbtns` `.stage` など）があっても、`#hero` の中にしか効かないので安全。
**`#hero` を外したり、`:root` に変数を書き足したりしないこと**。

## 2. ページへの入れ方

1. `hero-css` の style 要素を、ページの `</head>` の直前に入れる。
2. header 要素（`id="hero" class="hero"`）を、`<body>` のすぐあと（いまの `<div class="wrap">` の前）に入れる。
   ヒーローは画面の幅いっぱいに広がり、下の角が大きく丸い黒い帯になる（見本と同じ）。
3. `hero-js` の script 要素を、ページの最後の `</body>` の直前に入れる。
4. いまのページの先頭にある **`<h1>電気回路３次元シミュレーション</h1>` と、そのすぐ下の説明（`<p class="mini">…</p>`）は消す**
   （同じことをヒーローの題名と説明に書くので、二重になる）。
   ★ページの JS が この h1 や .mini を使っていないか、消す前に検索して確かめる。
5. ページ全体の表示スイッチ（単振動の「式・考え方エリアを閉じる」）は、見本からも外してある。付けない。

## 3. ヒーローの中身（電気回路のページ用に書きかえる）

★文言は **案**。作ったら千葉さんに見せて確かめる。

### 3-1 パンくず
- `楽楽（らくらく）高校物理 / 電磁気 / 電気回路` ＋ 英字 `Electric Circuits — Water Model`
- 「力学」のリンク先 `#sec-mechanics` を、トップページ（index.html）の電磁気の見出しの id に変える（`#sec-elemag` のはず。**index.html を開いて確かめる。index.html は編集しない**）。
- ロゴ（原子のマーク）の SVG はそのまま（オレンジの楕円 1 本もそのまま。サイト共通）。

### 3-2 題名・副題・説明
- 題名（`.t1` の中の `.nb`）：`電気回路` ← `data-sh` にも同じ文字を入れる（題名の影が左右にゆっくり動く演出に使う）
- 副題（`.t2`）：`〜電位は「高さ」、電流は「水の流れ」〜`
- 説明（`.lead2`）：いまのページの説明と「このシミュレーションの目的」をもとに 2〜3 行で。例：
  「電池は水をくみ上げるポンプ、抵抗は水車。自分で回路を組んで立体図にし、電位と電流のようすを目で見て理解しよう。直流からコンデンサー・コイル、交流まで。」
- 題名が長くて 1 行に入らないときは、見本の `.nb` のように**意味の切れ目で span を分けて**折り返させる（`電気回路の` `水流モデル` など）。

### 3-3 コンテンツ一覧のボタンとパネル
- ボタンはそのまま。パネルの中身は、このページの**モード（タブ ①②③）と、その下の見出し（h2）**から作る。
- 項目を押したら：タブなら、そのタブのボタンを `click()` してから、シミュレーションの位置へスクロール。見出しなら、その見出しへスクロール。

### 3-4 ステージ（canvas のアニメ）★いちばん作りかえるところ
単振動のアニメ（等速円運動・ばね・正弦曲線）を、**このページの核心を 1 枚で見せるアニメ**に作りかえる。案：

- **水流モデルの回路を真横から見た図**：左に「ポンプ（電池）」が水を高いところへくみ上げ、上の水路を流れた水が「水車（抵抗）」で高さを失って下へ落ち、ポンプにもどる。
- 水の粒（ストロボのように一定間隔の点）がぐるぐる回り、**どこでも同じ量が流れている（電流はどこでも同じ）**ことと、**高さ＝電位が電池で上がり抵抗で下がる**ことが見える。
- 右はしに「高さ（電位）」の目盛りを置き、`V`（電池で上がった高さ）＝ 抵抗で下がった高さ、を示すとよい。
- 説明の文（`.sct`）も、このアニメに合わせて書きかえる。

アニメの作り方の約束（見本の `initStage` をそのまま使う部分）：
- `setup()`：canvas の大きさを測って、図の寸法を**幅・高さの割合**で決める（スマホでもはみ出さない）。
- `draw(t)`：時刻 t の絵を 1 枚描く。**ここだけ作りかえる**。
- 止める条件はそのまま：画面の外・タブが見えない・「動きを減らす」設定・一時停止ボタン。🐢スローもそのまま。
- `window.__hero.frame(t)`：決まった瞬間を描かせる確認用。残す。
- **このページのアニメと同時に動かさない**：見本は `button.b.play` を押したら止める。このページでは
  「立体図を表示、アニメスタート」（`#btn-convert` `#btn-convert2`）と「▶ 再生」（`#btn-play`）を押したら止めるように、セレクタを書きかえる。

### 3-5 3 つのカード（`.ideas`）
タブ ①②③ に 1 枚ずつ。押したら、そのタブのボタンを `click()` してシミュレーションの位置へスクロール（`href` は `#`＋行き先、クリックで `preventDefault`）。案：

| | 式（KaTeX） | ひとこと |
|---|---|---|
| ① 抵抗の直流回路 | `V = RI` | 電位は高さ、電流は水の流れ |
| ② コンデンサー・コイル | `Q = CV` | コンデンサーは水をためるタンク |
| ③ 交流回路 | `V = V_0\sin\omega t` | 流れの向きが周期的に入れかわる |

- 式は、このページにすでにある KaTeX で組む（見本は組んだあとの HTML が入っているので、書きかえるときは `katex.render` などで組み直す）。
