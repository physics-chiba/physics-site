### 色（UI の色はこれだけ。図の中の物理の色は一切変えない）
| 名前 | 値 | 使いどころ |
|---|---|---|
| 紙 `--paper` | `#f5f3ee`（`--paper-2` `#ede9e1`・`--paper-3` `#e4dfd5`） | ページの地・くぼみ（操作の箱） |
| 白 `--surface` | `#ffffff` | カード・グラフの面 |
| 墨 `--ink` | `#14171c`（`--ink-2` `#3a414c`・`--ink-3` `#69717d`・`--ink-4` `#9aa1ab`） | 文字・選択中のボタン・番号のピル |
| 線 `--rule` | `#e6e1d7`（`--rule-2` `#d5cfc3`） | ごく薄い区切り |
| アクセント `--brand` | `#e07b18`（`-600` `#c9670c`・`-700` `#9c4e06`・`-50` `#fdf4e8`・`-100` `#fae4c8`） | ▶ スタート・選択中の下線・章番号の英字・プリセット |
| 夜 `--night` | `#0e1115`（`--night-2` `#161a20`） | ヒーロー・フッター |
- 暗い地（ヒーロー）で物理の色を使うときだけ、同じ色相の**明るい版**にする（例：A 赤 `#ff6b5b`・B 青 `#5aa7ff`・力積マゼンタ `#ff4fae`・白 `#f6f2e9`）。本文の図は元の色のまま。
- 状態の色：緑（ヒント・証明）`#1c8f4a`／地 `#effaf3`・`#f1f7f2`、青（注）`#1663b5`／地 `#f2f6fb`、紫（ハイライト）`rgba(122,90,168,.28)`。

### 書体
- 日本語：システムのゴシック（`--f-jp`。Windows は "Yu Gothic Medium" で細さを避ける）。見出しは `--f-jph`。
- ラテン文字・章番号・英字の副題：**内蔵済みの KaTeX_Main**（`--f-serif`、教科書・論文の雰囲気。外部フォントは読まない）。
- 動く数字は `font-variant-numeric:tabular-nums`（ゴシックのまま。serif の数字は「45 °」のように崩れることがある）。

### 形・影・余白・動き
- **枠線で囲まない**。余白と面の色（くぼみ＝紙色、カード＝白）で区切る。
- 角丸は 4 段：10／14／20／28 px（`--r-s` `--r` `--r-l` `--r-xl`）。ボタン・番号・タグはピル（999px）。
- 影は 2 段：`--sh-1`（ごく弱い）・`--sh-2`（カード）。パネル・案内だけ `--sh-3`。
- 動きは `--ease:cubic-bezier(.2,.75,.2,1)`。**無限にくり返す演出は `opacity`・`transform` だけ**（重さ対策・4 章の最後）。
  `prefers-reduced-motion` では止める。ヒーローのアニメは画面外・タブ非表示・ほかのシム再生中は止める。

### ページの構成（上から）
1. **ヒーロー**（暗い地・方眼・オレンジの光・下の角を大きく丸める）：パンくず → 全体スイッチ（トグル形）→ 大見出し（2 行目はオレンジの副題）
   → リード＋「コンテンツ一覧」ボタン（オレンジ）→ **ステージ（そのページの核心を見せる canvas アニメ＋説明＋操作）** → **要点カード 3 枚**（押すとその章へ）。
2. **タブ列**（画面幅いっぱい・上に固定・すりガラス）：左はしにホーム＋ページ一覧 → 章のタブ（①＋名前、選択中は墨の文字＋オレンジの下線）→ 下に読み進みの線。
   ヒーローを過ぎると小さな題名（1380px 以上）。641〜1239px は 2 段に折り返し、640px 以下は 1 段で横に送る（右はしをぼかす）。
3. **章の扉**：丸の中の大きな章番号（serif）＋「Chapter 01 — 英語の副題」（オレンジの斜体）＋大見出し＋リード。下にセクションへのピル。
4. **セクションのカード**：白・角丸 28px・やわらかい影。番号は墨のピル（①-1）。左の列＝図と操作、右の列（紙色）＝式・考え方。
5. **操作**：ボタンは全部ピル。▶ スタートだけオレンジで塗る。チェックボックスはトグル。スライドバーは細い溝＋塗り（`--p`）＋白縁のつまみ、目盛りの文字はつまみの位置。
6. **図の中**：方眼ノートの地（地面と同じ座標）、UI の灰色を紙と墨に、吹き出しは角丸＋ふわっと影、グラフは白い面・外枠なし。
7. **フッター**（暗い地）：英字の題名＋日本語の題名＋章の目次＋ホーム・ページ一覧＋「ページの一番上へ」。**共通フッターのスクリプトは一字も変えない**。

   ・ヒーローの「衝突のステージ」：A（m）が静止した B（2m）に当たる。e を 1 → 0.5 → 0 と変えてくり返す。
     ストロボ写真のように一定の時間ごとの位置を残し、上には運動量の「足し算の図」を出す。
     赤（p_A）＋青（p_B）の和＝白い矢印は、衝突の前後でまったく同じ長さのまま。
   ・スライドバーの塗り（--p）、タブ列の下の進み具合（--prog）。
   ・画面に見えていないとき・動きを減らす設定のときは動かさない（重くしない：第 21 回の教訓）。
   ========================================================================= */
(function(){
  "use strict";
  const RM = window.matchMedia && window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  const C = { A:"#ff6b5b", B:"#5aa7ff", J:"#ff4fae", T:"#f6f2e9", dim:"rgba(243,239,230,.42)", grid:"rgba(243,239,230,.10)", brand:"#e07b18" };
  const SER = '"KaTeX_Main","Times New Roman",serif', MATH = '"KaTeX_Math","KaTeX_Main",serif', MONO = '"KaTeX_Typewriter",ui-monospace,monospace',
        JP = '"Hiragino Sans","Hiragino Kaku Gothic ProN","Yu Gothic",YuGothic,"Noto Sans JP",Meiryo,sans-serif';
  const ES = [1.0, 0.5, 0.0], ENAME = {1:"弾性衝突", 0.5:"非弾性衝突", 0:"完全非弾性衝突"};
  const mA = 1, mB = 2;

  function initStage(){

    const ctx = cv.getContext("2d");

    function setup(){

      W = Math.max(280, r.width); H = Math.max(160, r.height);
      cv.width = Math.round(W*dpr); cv.height = Math.round(H*dpr); ctx.setTransform(dpr,0,0,dpr,0,0);
      const s = Math.max(W<640? .86 : .72, Math.min(1.15, H/260));
      const rA = 19*s, rB = 19*s*Math.SQRT2, gY = H*0.86;
      const xA0 = W*0.10 + rA, xB0 = W*0.52, gap = xB0 - rB - (xA0 + rA);
      const tc = 1.25, v = gap/tc;
      sc = { s, rA, rB, gY, xA0, xB0, tc, v, k: Math.min(W*0.15, 190) };
    }
    function state(tt, e){
      const { xA0, xB0, tc, v } = sc;
      if(tt < tc) return { xA:xA0+v*tt, xB:xB0, vA:v, vB:0 };
      const vA1 = (mA - e*mB)/(mA+mB)*v, vB1 = (1+e)*mA/(mA+mB)*v, d = tt - tc;
      return { xA:xA0+v*tc+vA1*d, xB:xB0+vB1*d, vA:vA1, vB:vB1 };
    }
    /* 矢印（ピクセル単位）。dbl＝二重線（このページの「速度」の約束）は使わず、運動量なので一本線 */
    function arrow(x1,y1,x2,y2,col,lw,head){
      const dx=x2-x1, dy=y2-y1, L=Math.hypot(dx,dy); if(L<2) return;
      const ux=dx/L, uy=dy/L, h=Math.min(head||10, L*0.6);
      ctx.save(); ctx.strokeStyle=col; ctx.fillStyle=col; ctx.lineWidth=lw||2.4; ctx.lineCap="round";
      ctx.beginPath(); ctx.moveTo(x1,y1); ctx.lineTo(x2-ux*h*0.7,y2-uy*h*0.7); ctx.stroke();
      ctx.beginPath(); ctx.moveTo(x2,y2); ctx.lineTo(x2-ux*h-uy*h*0.48,y2-uy*h+ux*h*0.48); ctx.lineTo(x2-ux*h+uy*h*0.48,y2-uy*h-ux*h*0.48); ctx.closePath(); ctx.fill();
      ctx.restore();
    }
    /* p_A のような「斜体の文字＋添え字」 */
    function sym(x,y,b,sub,col,size,align){
      ctx.save(); ctx.fillStyle=col; ctx.textBaseline="alphabetic";
      ctx.font = "italic "+size+"px "+MATH; const wb = ctx.measureText(b).width;
      ctx.font = Math.round(size*0.68)+"px "+SER; const ws = sub? ctx.measureText(sub).width : 0;
      let X = x; if(align==="center") X -= (wb+ws)/2; else if(align==="right") X -= wb+ws;
      ctx.font = "italic "+size+"px "+MATH; ctx.fillText(b, X, y);
      if(sub){ ctx.font = Math.round(size*0.68)+"px "+SER; ctx.fillText(sub, X+wb+1, y+size*0.22); }
      ctx.restore(); return wb+ws;
    }
    function ball(x,y,r,col,lab,alpha,ghost){
      ctx.save(); ctx.globalAlpha = alpha;
      if(ghost){ ctx.strokeStyle=col; ctx.lineWidth=1.3; ctx.beginPath(); ctx.arc(x,y,r,0,7); ctx.stroke(); ctx.restore(); return; }
      const g = ctx.createRadialGradient(x-r*.35,y-r*.4,r*.1,x,y,r);
      g.addColorStop(0,"#fff"); g.addColorStop(.18,col); g.addColorStop(1,shade(col,-.38));
      ctx.fillStyle=g; ctx.beginPath(); ctx.arc(x,y,r,0,7); ctx.fill();
      ctx.shadowColor=col; ctx.shadowBlur=24; ctx.globalAlpha=alpha*.35; ctx.beginPath(); ctx.arc(x,y,r,0,7); ctx.fill();
      ctx.shadowBlur=0; ctx.globalAlpha=alpha;
      ctx.fillStyle="#fff"; ctx.textAlign="center"; ctx.textBaseline="middle";
      ctx.font="italic "+Math.round(r*0.78)+"px "+MATH; ctx.fillText(lab, x, y+1);
      ctx.restore();
    }
    function shade(hex,k){ const n=parseInt(hex.slice(1),16); let r=n>>16,g=(n>>8)&255,b=n&255;
      const f=(c)=>Math.round(k<0? c*(1+k) : c+(255-c)*k); return "rgb("+f(r)+","+f(g)+","+f(b)+")"; }

    function draw(tt, e, fade){
      const { s, rA, rB, gY, k, tc, v } = sc;
      ctx.clearRect(0,0,W,H);
      ctx.save(); ctx.globalAlpha = fade;

      /* ストロボ（一定の時間ごとの位置） */
      ghosts.forEach((g,i)=>{ const a = 0.10 + 0.32*(i+1)/ghosts.length;
        ball(g.xA, gY-rA, rA, C.A, "", a, true); ball(g.xB, gY-rB, rB, C.B, "", a*(g.vB? 1 : .55), true); });

      /* 床に落ちる影（接地感） */
      [[q.xA,rA],[q.xB,rB]].forEach(([x,r])=>{ const g = ctx.createRadialGradient(x, gY+1, 0, x, gY+1, r*1.25);
        g.addColorStop(0,"rgba(0,0,0,.55)"); g.addColorStop(1,"rgba(0,0,0,0)"); ctx.fillStyle = g;
        ctx.save(); ctx.translate(x, gY+1); ctx.scale(1, .22); ctx.beginPath(); ctx.arc(0, 0, r*1.25, 0, 7); ctx.restore(); ctx.fill(); });
      ball(q.xA, gY-rA, rA, C.A, "m", 1, false);
      ball(q.xB, gY-rB, rB, C.B, "2m", 1, false);
      /* 物体のすぐ上：それぞれの運動量（一本線・その物体の色） */
      const pA = mA*q.vA/v, pB = mB*q.vB/v, fs = Math.round(15*s);
      const yA = gY - 2*rA - 14*s, yB = gY - 2*rB - 14*s;
      if(Math.abs(pA) > 0.01){ arrow(q.xA - pA*k/2, yA, q.xA + pA*k/2, yA, C.A, 2.6, 10);      
        sym(q.xA - Math.abs(pA)*k/2 - 7, yA+5, "p", "A", C.A, fs, "right"); }               // A の名前はいつも左はし（B と重ねない・向きが変わっても飛ばない）
      if(Math.abs(pB) > 0.01){ arrow(q.xB - pB*k/2, yB, q.xB + pB*k/2, yB, C.B, 2.6, 10);
        sym(q.xB + Math.abs(pB)*k/2 + 7, yB+5, "p", "B", C.B, fs, "left"); }
      /* 衝突の瞬間：作用・反作用の力積（マゼンタ）をしばらく出す。
         物体の絵の「上」に重ねて描く（e=0 では 2 球がくっついたままなので、下に描くと B が受ける力積が B の絵に隠れてしまう：第 27 回） */
      const dt = tt - tc;
      if(dt >= 0 && dt < 0.55){
        const a = 1 - dt/0.55, xc = q.xA + rA + ((q.xB - rB) - (q.xA + rA))/2, yc = gY - Math.min(rA,rB);
        const J = mA*(v - (mA - e*mB)/(mA+mB)*v)/v, L = 22 + J*k*0.34;
        ctx.save(); ctx.globalAlpha = fade*a;

        imp(xc-1, xc-1-L); imp(xc+1, xc+1+L);
        ctx.fillStyle=C.J; ctx.beginPath(); ctx.arc(xc, yc, 3.4, 0, 7); ctx.fill();
        ctx.font="700 "+Math.round(11.5*s)+"px "+JP; ctx.textAlign="center"; ctx.textBaseline="middle"; ctx.fillText("作用・反作用（力積は大きさが同じで逆向き）", xc, gY + (H-gY)/2 + 1);
        ctx.restore();
      }
      /* 左上：運動量の足し算（赤＋青＝白）。白い矢印は衝突の前後でまったく同じ */

      ctx.fillStyle = C.dim; ctx.font = "700 "+Math.max(11, Math.round(10.5*s))+"px "+JP; ctx.fillText("運動量の和", PX, Y0);
      const lw0 = ctx.measureText("運動量の和").width;
      if(W > 560){ ctx.font = "italic "+Math.round(10.5*s)+"px "+SER; ctx.fillText("vector sum", PX + lw0 + 8, Y0); }
      ctx.strokeStyle = "rgba(243,239,230,.22)"; ctx.setLineDash([2,3]); ctx.lineWidth = 1;
      ctx.beginPath(); ctx.moveTo(X0+.5, Y1-9); ctx.lineTo(X0+.5, Y2+7); ctx.moveTo(X0+k+.5, Y1-9); ctx.lineTo(X0+k+.5, Y2+7); ctx.stroke(); ctx.setLineDash([]);
      if(Math.abs(pA) > 0.01) arrow(X0, Y1, X0 + pA*k, Y1, C.A, 2.6, 10);
      ctx.strokeStyle = "rgba(243,239,230,.45)"; ctx.setLineDash([2,2]); ctx.beginPath(); ctx.moveTo(X0 + pA*k + .5, Y1); ctx.lineTo(X0 + pA*k + .5, Y1b); ctx.stroke(); ctx.setLineDash([]);   // 赤の先から青を始める（つなぎの点線）
      if(Math.abs(pB) > 0.01) arrow(X0 + pA*k, Y1b, X0 + (pA+pB)*k, Y1b, C.B, 2.6, 10);
      ctx.fillStyle = C.B; ctx.beginPath(); ctx.arc(X0 + pA*k, Y1b, 2.2, 0, 7); ctx.fill();
      arrow(X0, Y2, X0 + (pA+pB)*k, Y2, C.T, 3.4, 12);
      ctx.fillStyle = "#fff"; [Y1,Y2].forEach(yy=>{ ctx.beginPath(); ctx.arc(X0, yy, 2.6, 0, 7); ctx.fill(); });
      /* 白い矢印の右：p_A + p_B = 一定 */
      let x = X0 + k + 18; const f2 = Math.round(15*s);
      x += sym(x, Y2 + 5, "p", "A", C.A, f2, "left") + 6;
      ctx.fillStyle = C.T; ctx.font = f2+"px "+SER; ctx.fillText("+", x, Y2 + 5); x += ctx.measureText("+").width + 6;
      x += sym(x, Y2 + 5, "p", "B", C.B, f2, "left") + 8;
      ctx.fillStyle = C.T; ctx.font = f2+"px "+SER; ctx.fillText("=", x, Y2 + 5); x += ctx.measureText("=").width + 8;
      ctx.font = "700 "+Math.round(13.5*s)+"px "+JP; ctx.fillText("一定", x, Y2 + 5);
      /* 数値（等幅）：p_A・p_B・和（単位 mv） */
      if(W > 560){
        const fy = Y2 + 28*s, fz = Math.round(11.5*s), f = (z)=> (z>=0? "+" : "−") + Math.abs(z).toFixed(2);
        let xx = PX; const seg = (b, sb, col, val)=>{ xx += sym(xx, fy, b, sb, col, fz, "left") + 6;
          ctx.font = fz+"px "+MONO; ctx.fillStyle = "rgba(243,239,230,.7)"; ctx.fillText(val, xx, fy); xx += ctx.measureText(val).width + 18; };
        seg("p","A",C.A,f(pA)); seg("p","B",C.B,f(pB)); seg("p","A+B",C.T,f(pA+pB));
        ctx.font = "italic "+fz+"px "+SER; ctx.fillStyle = C.dim; ctx.fillText("× mv", xx - 10, fy);
      }
      /* 右上：いまの反発係数 */
      const es = (e===1? "1.0" : (e===0? "0" : "0.5")), fe = Math.round(24*s);
      ctx.textAlign = "left"; ctx.font = fe+"px "+SER; const wv = ctx.measureText(" = "+es).width;
      ctx.font = "italic "+fe+"px "+MATH; const we = ctx.measureText("e").width;
      const ex = W - 24 - wv - we, ey = Y0 + 16*s;
      ctx.fillStyle = C.T; ctx.fillText("e", ex, ey); ctx.font = fe+"px "+SER; ctx.fillText(" = "+es, ex + we, ey);
      ctx.textAlign = "right"; ctx.fillStyle = C.brand; ctx.font = "700 "+Math.round(11.5*s)+"px "+JP; ctx.fillText(ENAME[e], W - 24, ey + 22*s);
      ES.forEach((ee,i)=>{ ctx.beginPath(); ctx.arc(W - 27 - (2-i)*13, ey + 38*s, 3, 0, 7); ctx.fillStyle = (ee===e? C.brand : "rgba(243,239,230,.2)"); ctx.fill(); });
      ctx.restore();
    }
    const DUR = 3.1, FADE = 0.45;
    function frame(ts){
      if(!run) return;
      const dtm = last? Math.min(0.05,(ts-last)/1000) : 0; last = ts;
      t += dtm*rate;                       // スロー：時間の進みを遅くする（ストロボの間隔は物理の時間のまま）
      const e = (lockE!==null? lockE : ES[cyc % ES.length]);
      if(t - lastGhost >= 0.16 || lastGhost < 0){ const q = state(t, e); ghosts.push({xA:q.xA, xB:q.xB, vB:q.vB}); if(ghosts.length > 16) ghosts.shift(); lastGhost = t; }
      let fade = 1; if(t < FADE*0.6) fade = t/(FADE*0.6); else if(t > DUR - FADE) fade = Math.max(0,(DUR - t)/FADE);
      draw(t, e, fade);
      if(t >= DUR){ t = 0; cyc++; ghosts = []; lastGhost = -1; }
      raf = requestAnimationFrame(frame);
    }
    function start(){ if(run || RM || paused) return; run = true; last = 0; raf = requestAnimationFrame(frame); }
    function stop(){ run = false; cancelAnimationFrame(raf); }
    function still(e){                     /* 動きを減らす設定・一時停止：ストロボ写真 1 枚 */
      e = (e===undefined? (lockE!==null? lockE : 1) : e);
      ghosts = []; for(let tt=0; tt<=2.6; tt+=0.2){ const q = state(tt, e); ghosts.push({xA:q.xA, xB:q.xB, vB:q.vB}); }
      draw(2.6, e, 1);
    }
    setup(); if(RM) still(); else draw(0, 1, 0);
    /* 確認用（自動テストから決まった瞬間の絵を描かせる） */
    window.__hero = { frame:(tt,e)=>{ stop(); ghosts=[]; for(let u=0; u<=tt+1e-9; u+=0.16){ const q=state(u,e); ghosts.push({xA:q.xA,xB:q.xB,vB:q.vB}); } if(ghosts.length>16) ghosts=ghosts.slice(-16); draw(tt,e,1); }, start, stop };
    let rz = 0; window.addEventListener("resize", ()=>{ clearTimeout(rz); rz = setTimeout(()=>{ setup(); if(RM || paused) still(); }, 120); });
    if("IntersectionObserver" in window){
      new IntersectionObserver((es)=>{ es.forEach(en=>{ (en.isIntersecting && !document.hidden)? start() : stop(); }); }, {threshold:0.05}).observe(cv);
    } else start();
    document.addEventListener("visibilitychange", ()=>{ if(document.hidden) stop(); else { const r=cv.getBoundingClientRect(); if(r.bottom>0 && r.top<innerHeight) start(); } });
    /* 操作：e をえらぶ（自動＝1 → 0.5 → 0 のくり返し）・一時停止 */
    const ctl = document.querySelector("#hero .stagectl");
    if(ctl){
      const eb = ctl.querySelectorAll("button[data-e]"), pp = ctl.querySelector(".pp"), sl = ctl.querySelector(".slow");
      if(sl){ if(RM) sl.hidden = true;
        sl.addEventListener("click", ()=>{ rate = (rate===1? 0.3 : 1); sl.setAttribute("aria-pressed", rate<1? "true" : "false"); }); }
      eb.forEach(b=>b.addEventListener("click", ()=>{
        const v = b.dataset.e; lockE = (v==="auto"? null : parseFloat(v));
        eb.forEach(x=>x.setAttribute("aria-pressed", x===b? "true" : "false"));
        t = 0; ghosts = []; lastGhost = -1; if(lockE===null) cyc = 0;
        if(RM || paused) still(); }));

        pp.addEventListener("click", ()=>{ paused = !paused; pp.classList.toggle("paused", paused); pp.setAttribute("aria-label", paused? "再生" : "一時停止");
          if(paused){ stop(); still(); } else { t = 0; ghosts = []; lastGhost = -1; start(); } }); }
    }
    /* シムを再生したら止める（同時に動くのは 1 つだけ：第 21 回） */
    document.addEventListener("click", (ev)=>{ if(ev.target.closest && ev.target.closest("button.b.play")) stop(); }, true);
  }

  /* スライドバーの塗り：値が変わったら --p を書きかえる（プログラムから値を入れたときも、軽い見回りで拾う） */
  function syncRange(el){ const mn = parseFloat(el.min)||0, mx = parseFloat(el.max), v = parseFloat(el.value);
    const p = (isFinite(mx) && mx>mn)? (v-mn)/(mx-mn)*100 : 0; const s = p.toFixed(1)+"%";
    if(el._p !== s){ el._p = s; el.style.setProperty("--p", s); } }
  function initRanges(){
    document.addEventListener("input", (ev)=>{ if(ev.target && ev.target.type === "range") syncRange(ev.target); }, true);
    const sweep = ()=>{ if(document.hidden) return; document.querySelectorAll(".mode.on input[type=range], .modebar input[type=range]").forEach(syncRange); alignTicks(); };
    sweep(); setInterval(sweep, 120);
  }

  /* スライドバーの下の目盛りの文字（e=0・e=0.5・e=1）を、つまみの位置にきっちり合わせる（第 29 回）
     文字の列を「左右の余白」で合わせていたので、ラベルやボタンの幅が変わるとずれていた。
     スライドバーの実際の位置と幅を測り、つまみの中心が来る位置に 1 つずつ置く（等間隔の目盛りとして） */
  function alignTicks(){
    document.querySelectorAll(".mode.on .vrow.ticks, .modebar .vrow.ticks").forEach(tr=>{
      let row = tr.previousElementSibling; while(row && !row.querySelector("input[type=range]")) row = row.previousElementSibling;
      const inp = row && row.querySelector("input[type=range]"); if(!inp) return;
      const ri = inp.getBoundingClientRect(); if(ri.width < 10) return;
      tr.classList.add("tk-on");
      const rt = tr.getBoundingClientRect(), TH = 9, sp = tr.children, n = sp.length;
      const key = Math.round(ri.left - rt.left)+":"+Math.round(ri.width); if(tr._tk === key) return; tr._tk = key;
      for(let i=0; i<n; i++){ const f = n>1? i/(n-1) : 0.5; sp[i].style.left = (ri.left - rt.left + TH + f*(ri.width - 2*TH)).toFixed(1)+"px"; }
    });
  }
  window.addEventListener("resize", ()=>{ document.querySelectorAll(".vrow.ticks").forEach(t=>{ t._tk = null; }); alignTicks(); });

  function initDecorate(){

function parseSiteIndex(txt){
  try{
    const grab = (name)=>{ const i = txt.indexOf("const "+name+" = ["); if(i<0) return "";
      const j = txt.indexOf("\nconst ", i+10); return txt.slice(i, j<0? undefined : j); };

      const src = grab(nm); if(!src) return;

        const id = (chunk.match(/^([\w-]+)"/)||[])[1], name = (chunk.match(/name:"([^"]+)"/)||[])[1], color = (chunk.match(/color:"(#[0-9a-fA-F]{3,8})"/)||[])[1];

        while((m = re.exec(chunk))) items.push({ t:m[1], u:m[2] });
        if(id && name && items.length) out.push({ g:(id==="note"? "作成後記" : g), id, name, color:color||"#5b6672", items });
      });
    });
    const ORD = {"シミュレーション":0, "実験":1, "作成後記":2};

  }catch(e){ return null; }
