光の干渉　～薄膜の場合～

高校物理／シミュレーション教材　－　上から進んできた光が薄膜で 2 つに分かれ、強めあうか弱めあうかを確かめよう

【目的】

  1. 薄膜の経路差の式が成り立つ原理を理解し、実際の波の動きと干渉をビジュアル的に納得する。
  2. 反射のときに位相が π ずれる場合とずれない場合があり、それで条件式が入れかわることを理解する。
  3. 膜の厚さ・波長・屈折率・入射角 i を自分で変えて、強めあう／弱めあうが切りかわるのを体験する。
  4. 薄膜の干渉は「真上から覗いた場合」と「斜めから覗いた場合」を同じ考えでとらえればよいことを理解する。

光の干渉の考え方（3 ステップ）

教科書と同じ手順です。どの干渉の問題でも、この 3 つを順に踏めば解けます。

① 干渉する 2 つの光の光路差を求める

光①は上面 B₁ で反射、光②は A₂ から薄膜に入り C で反射して B₁ から出ます。

A₁A₂ は入射波の波面、B₁B₂ は屈折波の波面。A₁B₁（空気）と A₂B₂（薄膜）は光路が等しいので、B₁B₂ の上で光①と光②は同位相です。だから位相差をもたらすのは、そこから先の分だけ。

下面に関する B₁ の対称点を D とすると CB₁ = CD で、A₂・C・D は一直線。したがって

△B₁B₂D は ∠B₂ = 90°、∠B₁DB₂（＝∠CDB₁）= r、斜辺 B₁D = 2d の直角三角形なので

この分は薄膜（屈折率 n₁）の中なので、n₁ 倍して光路差になおすと

i = 0°（垂直入射）では A₂・B₁・B₂ が 1 点に重なり、経路差は単純な往復 2d、光路差は 2n₁d になります。

② 反射による位相の変化を調べる

屈折率が小 → 大の反射では位相が π ずれ、大 → 小の反射では変化しません。

③ 干渉の条件式を立てる

π ずれが正味 1 回あると、強めあう／弱めあうの条件式が入れかわります。

※ 図では、2 つの光が重なって見えなくならないよう、表示上わずかに横（水平）へずらして描いています。境界面上の点は面から離れません。入射角を大きくすると 2 つの光は自然に離れるので、ずらしは自動的に 0 になります。

薄膜はなぜ虹色に見えるのか（シャボン玉が虹色に見えるのも同じ原理）

キーワードは m = 0。強めあう波長のうちいちばん長い波長だけを考えれば、色のしくみが見えてきます。

① 強めあう条件を書く

薄膜の上も下も空気なら、上面（1 → n₁）だけで位相が π ずれる（正味 1 回）ので、強めあう条件は

この式を λ について解くと、強めあう波長は次のようにとびとびに並びます。

② m = 0 の光がいちばん強く目に飛びこむ

m が大きくなるほど分母が大きくなり、λ は短くなります。m = 0、つまり 0 次の明線が一番強いので、いまは m = 0 のみ考えます。（m = 1 以上は波長が短くなりすぎて、紫外線側へ抜けてしまい目に入りません。）

m = 0 とおくと、

この λ₀ が「その角度で目に飛びこむ色」です。

ただし m = 0 の山は、とても幅が広いことに注意。d = 120 nm・i = 30° では λ₀ = 592 nm ですが、明るさが半分になるのは 394 nm と 1183 nm、つまり可視光ぜんぶがそこそこ強く返ってきます（λ = 550 nm でも明るさ 98.6 %）。だから薄い膜の色は、絵の具のような純色ではなくうすい淡い色になり、角度を変えても色はゆっくりとしか変わりません。シャボン玉の色がパステル調に見えるのはこのためです。

③ 角度を変えると λ₀ が変わる ＝ 色が変わる

λ₀ = 4n₁d cos r の中で、角度によって変わるのは cos r だけです。見る角度 i を大きくすると r も大きくなり、cos r は小さくなる。つまり

図の下のグラフは、横軸が見る角度 i、縦軸が波長 λ、明るいところが強めあう波長です。白い曲線が λ₀ ＝ 4n₁d cos r。右へ行くほど（角度が大きいほど）曲線が下がる＝色が青へ寄るのがわかります。

④ だから 1 枚の膜が虹色に見える

白色光にはあらゆる λ が含まれるので、膜のどこを見ても「その方向の λ₀」が返ってきます。目に届く方向ごとに λ₀ がちがうので、1 枚の薄膜が場所ごと・角度ごとにちがう色に見える。これが虹色の正体です。

「▶ 角度を動かす」を押すと、角度とともに λ₀ と色が動くのを追えます。単色光に切りかえると、その波長が λ₀ になる角度だけが明るくなることを確かめられます。

⑤ プリズムとのちがい

プリズムの虹は、屈折率が波長でちがう（分散）ために色が分かれます。薄膜の虹色は干渉によるもので、しくみは別です。ただし「角度ごとにちがう色が出ていく」という見え方はよく似ています。

3. 補足：もっと深く知りたい人へ

反射防止コーティング（λ/4 膜）— メガネやカメラのレンズが青紫に見える理由

レンズ（n ≒ 1.52）の上に、n₁ ≒ 1.38 のフッ化マグネシウム MgF₂ を塗ると、上面（1 → 1.38）でも下面（1.38 → 1.52）でも「小 → 大」の反射になり、π ずれが 2 回、つまり正味 0 回になります。したがって弱めあう条件は 2n₁d = (m+1/2)λ。最小の厚さは m = 0 として d = λ/(4n₁)、いわゆる λ/4 膜です。

緑（λ ≒ 550 nm）で反射を消すように設計すると、赤と青の反射がわずかに残るのでレンズが青紫や紫に見えます。（このページの n₁ は 3 択なので、n₁ = 1.33、n₂ = 1.50 で近い状況をつくれます。）

さらに、屈折率のちがう膜を何十層も重ねた誘電体多層膜を使うと、特定の波長だけを 99.99 % 以上反射する鏡が作れます。レーザーの共振器や、重力波望遠鏡 KAGRA・LIGO の鏡もこの技術です。鏡の熱雑音（コーティングの原子のゆらぎ）が観測感度の限界を決めるため、結晶性コーティングなど新しい材料の研究が今も続いています。

もっと知りたい人へ： 反射防止膜（Wikipedia）／ 誘電体多層膜（Wikipedia）／ 大型低温重力波望遠鏡 KAGRA（国立天文台）

構造色 — 色素を使わない色

モルフォチョウの青、タマムシ、CD の裏面、シャボン玉。これらは色素ではなく、薄膜や微細構造による干渉で色がついています。色素の色とちがって見る角度で色が変わるのが特徴で、これは光路差 2n₁d cos r の cos r が角度で変わることに対応します。

工学的には「褪色しない塗料」「印刷できる構造色インク」として研究されています。

もっと知りたい人へ： 構造色（Wikipedia）／ 遊色効果（Wikipedia）

白色光を当てるとどうなるか

太陽光は多くの波長を含みます。膜厚 d が決まっていても、強めあう条件 2n₁d cos r = (m+1/2)λ を満たす λ は波長ごとにちがうので、ある波長は強めあい、別の波長は弱めあう。その結果、反射光は色づいて見えます。「薄膜が虹色に見える原理」モードで、スペクトルと見える色の関係を確かめられます。

もっと知りたい人へ： 薄膜干渉（Wikipedia）／ 光学薄膜（Wikipedia）

この教材で簡単にしていること（大学で学ぶ話）
  • 振幅を等しいとしています。実際の反射率はフレネルの式で決まり、空気／ガラスの反射は約 4 % しかありません。そのため弱めあっても完全には真っ暗になりません。この教材では条件式の理解を優先して、2 波を等振幅にしています。
  • 2 回目以降の反射を無視しています。本当は膜の中で何度も往復した光もわずかに出てきます。これらをすべて足し合わせたのがエアリーの式で、反射率が高い膜ではファブリ・ペロー干渉計のような鋭いピークになります。
  • 光を完全な単色波（無限に続く波）としています。実際の光には可干渉距離（コヒーレンス長）があり、白熱電球では数 μm 程度。膜が厚すぎると干渉が見えなくなるのはこのためです。
  • 光源のスペクトルを「平ら」としています。このページの「白色光」は、可視光の全波長（380〜780 nm）が同じ強さで一様に含まれると仮定した理想的な白（等エネルギー白色）です。現実の光源はそうではありません。太陽光はおよそ 5800 K の黒体放射に近く青〜緑がやや強め（さらに大気やフラウンホーファー線による細かい欠けがある）、白熱電球は 2800 K 程度で赤が強く青が弱い、白色 LED は青の鋭いピーク＋蛍光体の広い山という、でこぼこした分布をしています。ですから同じシャボン玉でも、太陽の下・蛍光灯の下・LED の下で見える色は微妙にちがいます。強めあう波長 λ₀ = 4n₁d cos r 自体は光源によらず同じで、変わるのは「その波長がどれだけ強く含まれていたか」＝見える色の濃さや色みです。
  • 色の計算について。「見える色」は CIE 1931 等色関数で反射スペクトルを積分し、sRGB になおして表示しています（虹色モードの扇は、m = 0 で強めあう波長 λ₀ の純色で塗り分けています）。実際のシャボン玉の色は、光源のスペクトル・膜の反射率・周囲の明るさ・目の順応でも変わります。
  • 膜厚測定への応用。逆に、干渉の色や分光反射スペクトルから膜厚を nm 単位で測る手法（偏光解析法・エリプソメトリー）は、半導体工場で日常的に使われています。
